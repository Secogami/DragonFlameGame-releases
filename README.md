# DragonFlame — Releases

2D-платформер о дракончике, который ищет свою семью через джунгли, горы и пустыни.

**Последняя версия: v0.3.0-demo** · [Скачать](../../releases)

## Что в демо (v0.3.0)
- **2 главы** из 10–12: джунгли (обучение, исследование) и густой лес с босс-ареной
- **3 типа врагов** — блоб, летун, чарджер — и **босс «Хищник Джунглей»** (3 фазы, шоковые волны)
- **Прогрессия:** двойной прыжок (за 500 очков), планирование (глава 2)
- **Сюжетные катсцены** между главами (иллюстрированные слайды)
- **Звук и музыка** — звуковые эффекты и атмосферно-оркестровые треки по главам
- **Меню настроек** — язык RU / EN, режим экрана (полноэкранный без рамки / оконный), громкость звука и музыки; выбор сохраняется; открывается из главного меню и паузы
- **2 режима** — обычный (3 жизни, retry) и хардкор (1 жизнь)
- **Сохранение прогресса** между главами

## Управление
| Клавиша | Действие |
|---|---|
| ← → | Движение |
| Пробел | Прыжок / двойной прыжок |
| Пробел (в воздухе, удержание) | Планирование (глава 2) |
| Z | Огненное дыхание |
| Esc | Пауза |

## Запуск
Распаковать архив и запустить `DragonFlame.exe` (файлы `.exe` и `.pck` должны лежать рядом). Установка не требуется.

## Ещё не реализовано
Главы 3–12 · стадии роста дракона · доп. способности (рывок, таран, хвостовая атака).

# EN

2D platformer about a little dragon searching for its family across jungles, mountains, and deserts.

**Latest: v0.3.0-demo** · [Download](../../releases)

## In the demo (v0.3.0)
- **2 chapters** of 10–12: jungle (tutorial, exploration) and dense forest with a boss arena
- **3 enemy types** — blob, flyer, charger — and **boss "Jungle Predator"** (3 phases, shockwaves)
- **Progression:** double jump (500 points), glide (chapter 2)
- **Story cutscenes** between chapters (illustrated slides)
- **Audio & music** — sound effects and atmospheric/orchestral per-chapter tracks
- **Settings menu** — language RU / EN, display mode (borderless fullscreen / windowed), sound & music volume; choices are saved; opens from the main menu and pause
- **2 modes** — normal (3 lives, retry) and hardcore (1 life)
- **Save system** between chapters

## Controls
| Key | Action |
|---|---|
| ← → | Move |
| Space | Jump / double jump |
| Space (in air, hold) | Glide (chapter 2) |
| Z | Fire breath |
| Esc | Pause |

## How to run
Extract the archive and run `DragonFlame.exe` (keep `.exe` and `.pck` together). No installation required.

## Not yet implemented
Chapters 3–12 · dragon growth stages · extra abilities (dash, charge, tail attack).
